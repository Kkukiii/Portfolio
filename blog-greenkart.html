Project Overview

GreenKart is an industry-grade e-commerce application designed with a focus on sustainability and user efficiency. The objective was to create a professional shopping experience that combines high performance with a clean, eco-friendly aesthetic.

Unlike basic educational projects, GreenKart was architected to handle complex user flows including dynamic cart management, interactive product filtering, and a secure-feeling checkout simulation.

Development Challenges

The primary challenge was implementing a seamless responsive experience across diverse device resolutions. Managing complex CSS grid layouts for product catalogs required extensive cross-browser testing and optimization.

Additionally, keeping the navigation flow intuitive while managing multiple sub-pages (Cart, Checkout, Account) provided significant insights into professional UI/UX design patterns.
